A complete interpreter for make.fun's tiny stack ISA: 32-bit wrapping arithmetic, 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their exit codes.

## Run it

```sh
node main.ts
```

Reads `/input/<id>/program.bin` and `/input/<id>/input.bin`, writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt`.
